Dopamine can now download and install updates itself.

- macOS uses Sparkle with signed update archives; Windows uses Velopack with Native AOT packages.
- Updates download in the background and install on quit. Use **Update and restart** in the menu or dashboard when an update is ready.
- Existing history, local categories and pairing codes stay in their original data directory.

Users of v0.0.4 and earlier need to install this version manually once. Future updater-enabled versions can update in place. On Windows, keep the full portable archive layout, or use `Dopamine-win-Setup.exe`; a bare EXE cannot update itself.

macOS is still not notarized. Accessibility permission may need to be enabled again after an update because builds currently use ad-hoc signatures.
