Dopamine now keeps all category choices local.

- Removed community category voting, network requests, sharing prompts and preferences, and the unused Supabase backend.
- Automatic app/site detection, app metadata, manual categories and per-window rules continue to work locally. Existing activity and local category choices are preserved.
- Updated the Chinese README and removed community sharing documentation from the READMEs and website.

Download `Dopamine-mac.zip` for macOS 12+ or `Dopamine-win.zip` for Windows 10+.

Existing apps with update checks enabled can detect this release through GitHub. The macOS app checks about 60 seconds after launch and then daily; turning update checks off and on triggers an immediate check. This is a notification and download link, not an automatic installation.
