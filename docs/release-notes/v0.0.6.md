Easier installs on macOS, Accessibility access that sticks, and Start with Windows.

- **macOS installer:** download `Dopamine-mac.dmg`, open it and drag Dopamine onto Applications.
- **Accessibility access stays on:** macOS builds are now signed with one stable certificate, so updates and reinstalls keep the permission. If Dopamine still shows the Accessibility notice, click **Open System Settings…** in its menu: it clears the stale entry left by an older copy and asks again.
- **Start with Windows:** a new tray menu item, off by default, starts Dopamine when you sign in. It follows the app if you move it.

Moving from v0.0.5 or earlier to this signed build, macOS asks for Accessibility access one last time. macOS builds are still not notarized: on first launch choose **Open Anyway** in System Settings → Privacy & Security.

Download `Dopamine-mac.dmg` for macOS 12+ or `Dopamine-win-Setup.exe` / `Dopamine-win.zip` for Windows 10+. Existing v0.0.5 installs update themselves.
