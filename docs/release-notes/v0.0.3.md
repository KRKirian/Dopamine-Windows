Erase what you'd rather not keep, pause for a while, choose a category for a single window, and hear about new versions.

## Download

| | |
| --- | --- |
| **Dopamine-mac.zip** | macOS 12 or later, Apple silicon and Intel. Move `Dopamine.app` to Applications. This build is not notarised: on first launch choose **Open Anyway** in System Settings → Privacy & Security, then allow Accessibility access so window titles can be read. |
| **Dopamine-win.zip** | Windows 10 or later, 64-bit. Unzip and run `DopamineWin.exe`; no .NET installation needed. |

**Updating on macOS:** the app isn't signed with an Apple Developer ID, so macOS treats each version as a new app and forgets its Accessibility access. After replacing the app, remove Dopamine from System Settings → Privacy & Security → Accessibility, add it again, and reopen it. Until then only app names are recorded, not window titles.

## What's new

- **Forget a window or a session.** Hover a window in the app list, or a session in the timeline list, and click the trash icon. The title is overwritten on disk and its time stops counting. This can't be undone.
- **Pause for a while.** Pause from the menu bar or tray for 15 minutes, an hour, until tomorrow, or until you resume. Timed pauses end by themselves.
- **A category for one window.** Click any window title to say "windows whose title contains … count as …", for that title or for every title sharing some words (a course code, a channel name), in every browser or just one app. Browsers no longer offer one category for the whole browser, since they show every kind of site. These rules stay on your computer and are never shared.
- **Better automatic categories.** Keywords now match plurals ("Lectures"), and course codes such as 15-445 or CS 61A count as study.
- **New version notices.** Once a day Dopamine asks GitHub whether a newer release is out and, if so, shows a download link in the menu bar or tray and the dashboard. The request carries nothing about you; turn it off at the bottom of the dashboard.
- **See every window.** "+N more windows" under an app now opens the full list.

## Known limits

- Private and incognito browser windows are still recorded; pause first, or forget them afterwards.
- On macOS, Accessibility access has to be granted again after each update (see above).
- On Windows, Microsoft Store apps share one host process, so they show a letter instead of their icon.
